# App Store And Google Play Readiness

## Required Before Submission

- App icon and splash screen based on Cloud&Core logo.
- iOS screenshots: 6.7", 6.5", 5.5" if required by store.
- Android screenshots: phone and tablet if tablet support is enabled.
- Privacy policy URL.
- Terms URL.
- Support URL and support email.
- In-app account deletion request.
- Notification permission copy and preference controls.
- Production Supabase project with RLS enabled.
- Crash reporting configured.
- TestFlight build.
- Google Play internal testing release.
- No production test data.
- Payment provider production keys configured in environment variables only.
- Webhook signature verification tested.

## Marketing Text

Cloud&Core Studio helps members browse classes, book in seconds, manage memberships, receive reminders, and stay connected with the studio in Hebrew or English.

## Privacy Positioning

The app requests only the permissions needed for bookings, reminders, and optional profile features. Personal data is protected with Supabase Row Level Security and can be deleted on request.
