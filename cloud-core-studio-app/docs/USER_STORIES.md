# User Stories

## Guest

- As a guest, I can view the public schedule so I can decide whether the studio fits me.
- As a guest, I can request a trial class when trials are enabled.
- As a guest, I can create an account with email, phone, Apple, or Google.

## Member

- As a member, I can see my next booking and membership status on the home screen.
- As a member, I can filter classes by type, instructor, level, location, availability, and time.
- As a member, I can book an open class after eligibility, capacity, and policy checks.
- As a member, I can join a waitlist when a class is full.
- As a member, I can confirm or decline a waitlist promotion inside a time limit.
- As a member, I can cancel according to policy and understand whether a credit returns.
- As a member, I can buy a package without the app depending on one hard-coded payment provider.
- As a member, I can request account deletion inside the app.

## Instructor

- As an instructor, I can view today's assigned classes.
- As an instructor, I can mark attendance and no-shows.
- As an instructor, I can add internal class notes visible only to staff.
- As an instructor, I can message participants through studio-approved channels.

## Admin

- As an admin, I can create, duplicate, publish, cancel, and edit classes.
- As an admin, I can create recurring class templates.
- As an admin, I can configure capacity, rooms, instructors, booking windows, cancellation windows, and waitlist rules.
- As an admin, I can manually add/remove members from classes.
- As an admin, I can manage packages, trials, subscriptions, coupons, and freezes.
- As an admin, I can export reports and audit staff actions.
