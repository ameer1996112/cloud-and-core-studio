# Pricing Review Guide

You said prices exist but you are not sure if they are good. Use this guide before posting them publicly.

## Recommended Pricing Position

Cloud & Core should not be the cheapest option. The brand is small-group, women-only, beginner-friendly, and guided personally by Yareen. That supports a calm premium price, especially because capacity is only 8-10.

Use a friendly-premium pricing tone:
- clear
- fair
- not apologetic
- not luxury-only
- not discount-heavy

## Pricing Structure To Consider

1. First Flight intro class
   - Lower than regular single class
   - Easy entry for beginners
   - Limited to first visit only

2. Single class
   - Useful for trial and occasional students
   - Should be higher per class than packages

3. 4-class package
   - Good first commitment after intro
   - Best for beginners

4. 8-class package
   - Better value
   - Helps monthly retention

5. Kids class
   - Price can differ from adult women class based on length, supervision, and parent expectations

6. Mom and daughter
   - Price as a pair/session, not only per person, if that is simpler locally

7. Birthday package
   - Separate from class pricing
   - Include duration, max number of kids, setup, photo time, and add-ons

## What To Check Before Publishing Prices

Costs:
- Rent or space cost
- Equipment and hammock maintenance
- Cleaning
- Marketing
- Time before/after class
- Birthday setup time
- Booking/admin time

Capacity:
- If class capacity is 8-10, every discount affects revenue strongly.
- Do not make the intro price so low that the regular price feels too high afterward.

Market:
- Compare with local yoga, Pilates, kids activity, and birthday activity prices.
- Aerial yoga can usually sit above simple group fitness if the experience feels personal and safe.

## Send For Review

When you send the actual prices, review them by asking:
- Is the intro price attractive but still respectful?
- Does the package price encourage returning?
- Is the birthday price high enough for setup and time?
- Are adult, kids, and mom-daughter offers easy to understand?
- Can the business reach its monthly goal with 8-10 capacity?
