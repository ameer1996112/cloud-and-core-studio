# Cloud & Core Open House Plan

Event name:

Cloud & Core Open House  
יום פתוח ב-Cloud & Core  
يوم مفتوح في Cloud & Core

Recommended event timing: within launch week, ideally Friday or Saturday afternoon/evening if that fits local habits and the women/kids audience.

## Event Concept

A calm open house where local women, mothers, girls, and partners can visit the studio, meet Yareen, see the hammocks, ask questions, watch a short beginner demo, and book a First Flight class.

The event should feel personal, not crowded. Use timed visit slots if needed.

## Event Goals

- Collect local leads
- Build trust before first classes
- Explain aerial yoga in a non-intimidating way
- Fill First Flight intro classes
- Create photo/video content for future posts with permission
- Build partner relationships

## Suggested Schedule

Option A: 2-hour open house

| Time | Activity |
|---|---|
| 00:00-00:15 | Welcome, studio tour, light refreshments |
| 00:15-00:25 | Yareen intro and safety explanation |
| 00:25-00:40 | Mini aerial yoga demo |
| 00:40-01:00 | Questions and photo corner |
| 01:00-01:20 | Kids / mom and daughter explanation |
| 01:20-01:45 | Booking station and lead collection |
| 01:45-02:00 | Final questions and closing reminder |

Option B: timed mini visits

- 30-minute visit slots
- 8-12 visitors per slot
- Best if space is limited

## Mini Demo Plan

Keep the demo beginner-friendly.

Demo flow:
1. Show hammock safety and support
2. Simple seated support
3. Gentle stretch
4. Beginner balance
5. Calm resting pose

Do not demonstrate extreme or intimidating poses in the opening event. The goal is confidence and curiosity, not performance.

## Booking Station

Set up a small table with:
- QR code to website
- Instagram handle
- Phone number
- Printed class interest form
- Lead tracker open on phone/laptop
- Price placeholder if not final: "Final prices will be posted soon"
- First Flight interest list

Questions to ask:
- Name
- Phone
- Preferred language
- Interested in: women / kids / mom and daughter / birthday
- Beginner? yes/no
- Best days/times

## Photo Corner

Use:
- Logo wall or clean corner
- Hammock detail
- Soft lighting
- Small sign:
  - Cloud & Core Studio
  - Float lighter. Feel stronger.
  - לרחף בקלילות. להתחזק מבפנים.
  - خفّة في الحركة، قوة من الداخل.

Permission rule:
Ask before filming or posting. For kids, get parent approval.

## Giveaway Idea

Simple giveaway:
- One First Flight class
- One mom and daughter mini session discount
- One birthday add-on discount

Entry:
- Follow Instagram
- Fill lead form
- Tag one local friend

Avoid complex giveaway mechanics before launch.

## Partner Collaboration Idea

Invite 2-3 local partners:
- Café: small drinks/snacks
- Beauty salon/local boutique: small gift card
- Photographer/influencer: short opening coverage

Partner gets:
- Story mention
- Partner tag in open house post
- Flyer placement at the studio
